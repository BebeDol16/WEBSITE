# Variante Shopify

La seconde version du projet prévoit une déclinaison Shopify conservant l’identité visuelle ELITE Mobile.

Structure cible :

```text
shopify/
├── assets/
├── config/
├── layout/
├── locales/
├── sections/
├── snippets/
└── templates/
```

Fonctions à transposer : accueil premium, collections, fiches produits avec variantes, recherche, filtres, panier Ajax latéral, ajout rapide, comptes clients et accès au checkout Shopify.

Le prototype Vite à la racine reste la source visuelle et fonctionnelle de référence. Les paiements et le checkout réel doivent être configurés dans l’administration Shopify.
